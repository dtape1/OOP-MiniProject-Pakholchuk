# Defense Q&A

## Архітектура

**Чому 4 шари а не просто один проєкт?**
Щоб Domain не залежав від інфраструктури. Завдяки цьому юніт-тести
пишуться без файлів і без JSON — тільки чиста логіка.

**Що таке Repository патерн і навіщо він тут?**
Repository ховає деталі зберігання за інтерфейсом. RentalService
викликає ICarRepository.GetAvailable() і не знає — це List в памяті
чи JSON файл. Можу замінити на базу даних не чіпаючи бізнес-логіку.

**Що таке Strategy патерн?**
Інтерфейс IPricingStrategy з методом Calculate(). Кожен тариф —
окремий клас. RentalService не має if/else для тарифів — просто
викликає strategy.Calculate(). Новий тариф = новий клас.

**Що таке Command патерн?**
Кожна дія меню реалізує ICommand з методом ExecuteAsync().
AppRunner зберігає Dictionary команд і викликає потрібну за ключем.
Program.cs стало 46 рядків замість 200.

## SOLID

**Як демонструється Single Responsibility?**
RentalService містить тільки бізнес-логіку. JsonCarRepository
займається тільки серіалізацією. AppRunner тільки керує меню.

**Як демонструється Open/Closed?**
Новий тариф — новий клас DiscountPricingStrategy без зміни
RentalService. Нова команда меню — новий клас без зміни AppRunner.

**Як демонструється Dependency Inversion?**
RentalService отримує ICarRepository в конструкторі.
У тестах підставляю InMemoryCarRepository,
у продакшні — JsonCarRepository. Сервіс не знає різниці.

## Тести

**Чому 42 юніт і 8 інтеграційних?**
Юніт-тести перевіряють доменну логіку швидко і ізольовано.
Інтеграційні перевіряють що збереження і завантаження JSON
працює коректно разом. Це test pyramid.

**Чому AppRunner не покритий тестами?**
Він залежить від Console.ReadLine() — це важко тестувати без
додаткових абстракцій. Це відомий технічний борг зафіксований
в iteration-3.md.

## Persistence

**Як відновлюється стан після перезапуску?**
При старті LoadAsync() читає JSON файли. При завантаженні оренд
відновлюю статус авто вручну — Active = MakeUnavailable(),
Completed/Cancelled = MakeAvailable().

**Що станеться якщо JSON пошкоджений?**
JsonException перехоплюється, виводиться попередження і програма
стартує з порожнім списком. Перевірено інтеграційним тестом
LoadAsync_CorruptedJson_ReturnsEmpty.

## Загальні питання

**Що б змінив якби починав заново?**
Виніс би Console.ReadLine() за інтерфейс щоб команди можна було
тестувати. Також додав би валідацію email і телефону в домені.

**Чим FINAL_REPORT відрізняється від README?**
README — короткий опис для нового користувача: як запустити
і що вміє програма. FINAL_REPORT — технічний звіт про рішення,
компроміси і що було складним під час розробки.

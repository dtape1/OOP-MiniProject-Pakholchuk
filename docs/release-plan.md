# Release Plan — v1.0.0

## Що входить у v1.0.0
- Повна доменна модель (Car, Client, Rental, RentalStatus)
- JSON persistence (збереження/відновлення стану)
- 5 use cases через консольне меню
- Strategy патерн для тарифів
- Command патерн для меню
- 50 тестів (42 юніт + 8 інтеграційних)
- GitHub Actions CI
- Повний комплект документації

## Що переноситься після курсу
- Графічний інтерфейс (WPF або веб)
- База даних замість JSON
- Автентифікація користувачів
- Звіти у PDF
- REST API

## Допустимий технічний борг
- AppRunner і команди не покриті тестами (залежать від Console)
- Немає валідації формату email і телефону
- Немає обмеження активних оренд на клієнта
- Немає логування у файл

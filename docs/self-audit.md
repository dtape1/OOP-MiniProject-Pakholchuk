## Найкраще покриті теми (3-5)
1. **Тестування** — 50 тестів, Theory, інтеграційні з temp файлами, coverlet
2. **SOLID** — кожен принцип демонструється конкретними класами
3. **Патерни** — Strategy, Repository, Command реально використовуються
4. **Обробка помилок** — доменні винятки, graceful fallback при пошкодженому JSON
5. **Async/await** — весь persistence шар асинхронний

## Що хочу добудувати (3 теми)
1. **Делегати** — додати гнучкий фільтр на Func<Car, bool> в RentalService
2. **Розширена аналітика** — побудувати LINQ-звіт що використовує цей фільтр
3. **Theory тести** — покрити фільтр параметризованими тестами

## Чому саме ці теми
Делегати використані мінімально — тільки Func<Task> для збереження.
Гнучкий фільтр на делегатах природно лягає на існуючий RentalService
і дозволяє побудувати справжню аналітику через LINQ.
Кожне розширення використовує результат попереднього — це справжній
ланцюжок а не три окремі задачі.
